# LingoLens Figma Make 提示词

分两轮使用：先发「第一轮：原型」，确认信息架构和流程后，再发「第二轮：UI 与交互」。

---

## 第一轮：原型（低保真，聚焦信息架构与流程）

```
为一款 macOS 原生桌面应用 LingoLens 设计可点击的低保真原型（灰阶线框即可，不要做视觉风格）。

【产品定位】
完全本地运行的 macOS 翻译与会议助手，所有 AI 推理都在本机（本地 MLX 模型 + 系统语音识别），不连云端。
目标用户：经常开英文会议、阅读外文资料的中文职场用户。
平台：macOS 26，Apple Silicon，菜单栏常驻应用（默认无 Dock 图标）+ 一个主窗口 + 若干悬浮窗。

【三大核心功能】
1. 划词翻译：任意应用中选中文字，按快捷键 ⌥D，在鼠标附近弹出翻译浮窗。
2. 实时语音翻译：采集系统音频（对方）和麦克风（我），实时转写，在屏幕底部的字幕浮窗显示双语字幕。
3. 会议纪要：音频会话期间实时保存转写，会后一键生成结构化纪要（摘要/关键讨论/决策/行动项/待定问题）。

【需要的界面（每个都要有原型帧）】
A. 菜单栏下拉面板（点击菜单栏图标弹出，宽约 320px）
   - 顶部：当前常驻模型名 + 状态（加载中/就绪/错误）
   - 大按钮：「开始音频会话」，运行中变为计时器 + 停止
   - 会话配置：音频源（系统音频/麦克风/两者）、对方语言、我的语言、开关「显示字幕」「记录会议」
   - 快捷入口：划词翻译（显示快捷键）、打开主窗口、退出
B. 首次启动引导（3–4 步）：欢迎 → 准备本地运行环境（进度条）→ 下载/选择模型 → 授予权限（辅助功能、麦克风、系统音频录制）→ 试一试 ⌥D
C. 主窗口（约 960×640，左侧边栏导航，替代现在的顶部 Tab）
   侧边栏项：首页、会议、模型、设置
   1) 首页：模型与运行时状态卡片、最近会议、快捷操作（翻译剪贴板、打开空白翻译窗、开始会话）、权限异常提醒
   2) 会议：左列表（标题、日期、时长、是否已有纪要、搜索）+ 右详情
      详情为左右分栏：左转写（时间戳、「我/对方」标签、原文+译文、可搜索、可逐条编辑），右纪要（模板选择、输出语言、生成/停止/重新生成、流式 Markdown、复制/导出 .md）
   3) 模型：已安装模型列表（参数量、量化位数、磁盘大小、预估内存、是否视觉、来源：扫描/导入/下载）、设为常驻、删除；「导入文件夹」「从 Hugging Face 下载」（带进度、取消）；运行时状态与日志入口
   4) 设置（分组）：通用（目标语言、快捷键录制、开机启动）、场景（划词翻译/实时字幕/会议纪要各自选择模型与生成参数）、音频会话、纪要模板、权限状态面板
D. 划词翻译浮窗（约 420×260，出现在鼠标附近，不抢焦点）
   原文（可编辑，⌘Enter 重译）、源语言→目标语言切换、译文（流式）、底部灰字：模型名 · 首字延迟 · tok/s；操作：复制、固定（Pin）、关闭（Esc）
   状态：模型加载中 / 翻译中 / 完成 / 出错 / 未取到选中文字（空输入态）
E. 实时字幕浮窗（半透明置顶，默认屏幕底部，宽约 800）
   最近 3–5 条，每条：说话人标签（我/对方用不同颜色）、原文小字、译文大字；未定稿的句子灰色显示
   悬停时显示控制条：暂停、点击穿透开关、字号、透明度、关闭
F. 全局状态与错误：模型启动失败、内存不足、权限被拒、运行时安装失败（都要给出下一步操作按钮，如「查看日志」「换小模型」「去授权」「重试」）

【需要串起来的关键流程】
1. 首次启动 → 引导完成 → 首页
2. 在其他应用选中文字 → ⌥D → 翻译浮窗 → 复制/固定/关闭
3. 菜单栏 → 开始音频会话（勾选记录会议）→ 字幕浮窗出现 → 停止 → 通知「会议已保存」→ 点击进入会议详情 → 生成纪要 → 导出
4. 模型页 → 从 Hugging Face 下载 → 设为常驻 → 首页状态变为就绪

请输出：每个界面一帧 + 关键状态变体 + 流程连线，界面文案全部使用简体中文。
```

## 第二轮：UI 与交互（在原型基础上做高保真）

```
在上一版 LingoLens 原型的基础上，保持信息架构和流程不变，做高保真视觉与交互设计。

【视觉方向】
- 遵循 macOS 26 原生设计语言：Liquid Glass 材质、半透明侧边栏、SF Pro / PingFang SC 字体、SF Symbols 图标、系统圆角与间距
- 冷静、专注、专业的工具感，避免营销风格；信息密度适中
- 同时提供浅色和深色模式
- 品牌色：一个主色（建议靛蓝 #4F5BD5 附近）用于主按钮与选中态；「我」用蓝色系，「对方」用橙/琥珀色系，在字幕、转写、会议详情中保持一致
- 建立基础设计系统：颜色 token、字号层级、间距（4/8 栅格）、按钮/输入框/开关/分段控件/标签/状态徽章/卡片/进度条组件及其各状态

【交互要求】
1. 翻译浮窗
   - 出现：从鼠标位置淡入 + 轻微放大（150ms），不抢焦点；点击外部自动关闭（固定时除外）
   - 译文流式逐字出现，带光标；完成后底部显示性能信息
   - 原文区默认折叠为 2 行，点击展开编辑；⌘Enter 重译，⌘C 复制译文并给出「已复制」轻提示
2. 字幕浮窗
   - 新句子从底部滑入，旧句子上移淡出；未定稿句子灰色+轻微闪烁，定稿后切换为正常色并出现译文
   - 非悬停时只显示文字（极简），悬停时显示控制条；点击穿透开启时显示一个小图标提示
   - 可拖动、可从边缘缩放，提供「紧凑/标准/大字」三档
3. 菜单栏面板
   - 会话运行中：顶部显示红点 + 计时 + 两路音量电平条（对方/我），一眼确认在收音
   - 开关和语言选择在会话运行中可改，改动即时生效
4. 会议详情
   - 转写与纪要分栏可拖动宽度；点击纪要中的行动项可高亮定位到对应转写时间点
   - 生成纪要时显示阶段进度（长会议：分段提炼 n/m → 合并），可随时停止
   - 转写逐条编辑：悬停出现编辑图标，行内编辑，Enter 保存，Esc 取消
5. 模型页
   - 每个模型卡片显示内存占用与本机可用内存对比条，超出时警示色并禁用「加载」
   - 下载显示速度、剩余时间、可暂停/取消
6. 空状态与错误
   - 每个列表都有空状态插画 + 一个明确的下一步按钮
   - 错误使用页内横幅而不是模态弹窗，附带「查看日志」「重试」等操作

【输出】
- 所有界面的浅色/深色高保真稿
- 组件库页（组件 + 状态变体）
- 关键交互的原型连线和动效说明（时长、缓动）
- 文案使用简体中文
```
